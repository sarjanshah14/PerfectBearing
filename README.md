# Perfect Bearing — website

Website for **Perfect Bearing**, an industrial bearing exporter. Built by me for the business.

**Live:** https://www.perfectbearing.co.in

## What it is

A product catalog for industrial bearings. Visitors browse by category, search with autocomplete, open a product page with specs, and send an inquiry by WhatsApp or through the contact form. Plain HTML, CSS and JavaScript, with no framework, hosted on Vercel.

## Features

- Category pages (`type.html`) and product pages (`bearing.html`) filled from a JSON database
- About 1,070 static product pages in `bearings/` for search engines, generated by `bearings-pages/generate-bearing-pages.js`
- Search with autocomplete, light/dark theme, mobile-friendly layout
- Contact form via EmailJS, WhatsApp inquiry links, Google Analytics
- SEO and hardening: sitemap, canonical URLs, structured data, custom 404, security headers (CSP, HSTS) in `vercel.json`

## Files

```
index.html, type.html, bearing.html, 404.html   pages
styles.css, script.js                           styling and site logic
latest db 1.json                                product database used by the site
bearings/                                       generated product pages
bearings-pages/generate-bearing-pages.js        script that generates them
photos/, brand/                                 product images and brand logos
sitemap.xml, robots.txt                         for search engines
vercel.json                                     clean URLs, headers, redirects
```

## Run it locally

The site loads its data with `fetch()`, so serve it over HTTP instead of opening the file directly:

```bash
python3 -m http.server
```

To regenerate product pages after editing the database:

```bash
node bearings-pages/generate-bearing-pages.js
```
